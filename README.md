# Tic Tac

Tic Tac is a browser-based tic-tac-toe game where you play the classic 3x3 grid
against a computer opponent. Place three of your marks in a row - horizontally,
vertically, or diagonally - before the computer does.

## Tech Stack

- [React](https://react.dev) 18
- [Vite](https://vite.dev) 5
- [Vitest](https://vitest.dev)

## Getting Started

```sh
# Install dependencies
npm install

# Start the dev server
npm run dev

# Run tests once
npm test

# Build for production
npm run build
```
